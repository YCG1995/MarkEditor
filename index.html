MarkEditor · 离线 Markdown 编辑器
单文件、零依赖、可完全离线运行的所见即所得 Markdown 编辑器，支持：
排版：标题（H1–H6，可自动编号）/ 粗斜体 / 删除线 / 高亮 / 下划线 / 行内代码 / 代码块（语法高亮、行号、一键复制）/ 引用 / 有序·无序·任务列表（可嵌套、自动编号）/ 表格（浮动工具栏增删行列、切换对齐、导出 CSV）/ 链接 / 图片（拖拽/粘贴插入，可内嵌 Base64）/ 分割线 / 脚注 / Callout 提示块 / Front Matter。
进阶：数学公式（TeX 子集，块级与行内，可点击编辑）/ Mermaid 流程图 / [TOC] 目录 / 源码模式 / 专注模式（F8）/ 打字机模式（F9）/ 全屏（F11）/ 多主题 / 缩放 / 页面宽度 / 查找替换 / 命令面板（Ctrl+Shift+P）。
大纲：左侧大纲随标题自动生成，支持层级折叠/展开与一键全部折叠；手机等窄屏（≤820px）默认折叠，只显示顶层标题。
文件：工作区管理（文件树、右键菜单：重命名/副本/删除/复制路径/属性等）/ 快速打开（Ctrl+P）/ 工作区全局搜索（Ctrl+Shift+F）/ 打开保存 .md / 导出 HTML（静态，零脚本）/ 导出可编辑 HTML（内嵌文档，禁脚本环境自动静态降级）/ 导出 Word（.doc）。
提示：直接输入 Markdown 语法即可即时渲染；Ctrl+Shift+P 打开命令面板搜索全部 72 个命令；Ctrl+, 打开偏好设置。
